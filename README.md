# CCSR-R-Tool

This repository outlines how to use the Clinical Classifications Software Refined (CCSR) tool in R. CCSR aggregates ICD-10 diagnosis and procedure codes into clinically meaningful groupings for analysis. 

Currently, the AHRQ's HCUP website only contains SAS documentation for using the CCSR tool, so this respository serves as an R alternative for CCSR mapping.

Attached, you can find an R script with instructions on how to use the CCSR tool for translating ICD-10 codes and a synthetic dataset for practicing.
